# O que mudou — e o que não mudou

Deck da palestra de **Mateus** na universidade onde se formou. Visual editorial, uma ideia por slide. O tom é de relato: compartilhar o que a caminhada ensinou, sem se colocar como exemplo.

O Miro ([board da palestra](https://miro.com/app/board/uXjVHp8H_bQ=/)) não pôde ser escrito daqui — a autenticação do Miro só abre no Cursor desktop. Este app é o deck apresentável, tela cheia.

## Rodar

```bash
npm install
npm run dev
```

Abre em [http://127.0.0.1:43147](http://127.0.0.1:43147).

## No palco

| Tecla | Ação |
|---|---|
| `→` `espaço` | Próximo |
| `←` | Anterior |
| `F` | Tela cheia |
| `N` | Notas de fala |
| `?` | Atalhos |
| clique direita / esquerda | Avançar / voltar |

No celular, deslize.

## Texto da palestra

| Arquivo | Para que serve |
|---|---|
| [PLANO.md](PLANO.md) | Objetivo, público, tese, o que evitar |
| [ROTEIRO.md](ROTEIRO.md) | Texto falado, bloco a bloco |
| [SLIDES.md](SLIDES.md) | Mapa slide a slide |

Quando o Miro estiver autenticado no desktop, dá para transpor este deck para o board.
